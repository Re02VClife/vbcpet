# 硬件框图 (Block Diagram)

```
                     USB-C (5V) ── 供电 + USB2.0 OTG (烧录/数据/串口)
                            │
   ┌────────────────────────┴────────────────────────────────────────────┐
   │  电源: MP2315 Buck (5V→3.3V) + MT3608 Boost (3.3V→12.2V 背光)       │
   └────────────────────────┬────────────────────────────────────────────┘
                            │ +3V3
   ┌────────────────────────┴────────────────────────────────────────────┐
   │                   ESP32-P4C6-Core (主控)                             │
   │     P4 RISC-V x2 360MHz + C6 WiFi6/BLE + 16MB Flash + 32MB PSRAM    │
   └── I2C ──┬──── I2S ──┬──── MIPI-DSI ──┬──── GPIO ──┬── USB OTG ─────┘
             │           │                │            │
   ┌─────────▼──┐  ┌─────▼──────────┐  ┌──▼──────────┐ │  ┌──────────────┐
   │ NT3H2111  │  │ MAX98357A 模块 │  │ 4.3" DSI 屏 │ │  │ 4×凯华轴座  │
   │ NFC Tag   │  │ + ZTS6672×2   │  │ 480×800     │ │  │ + SK6812×4  │
   │ + 触摸    │  │ I2S 全数字音频│  │ ST7102+触摸 │ │  │ 按键背光     │
   └───────────┘  └───────────────┘  └─────────────┘ │  └──────────────┘
                                                     │  ┌──────────────┐
      I2C 总线: NT3H2111(0x55) + 触摸(ST7102)        │  │ RST + 天线   │
      I2S 总线: MAX98357A + ZTS6672×2 (无 MCLK)      └──┘              │
                                                     └─────────────────┘

   USB-A 外设口 (FS OTG, GPIO26/27) ── 机械臂 / 电子设备 / 手机互连 / 低速摄像头
                     │  VBUS 5V (PPTC 500mA 限流) + USBLC6-2SC6 ESD
```

## 说明
- **模组**：P4C6-Core 一体模组，P4+C6 SDIO 内部互联，单 3.3V 供电
- **音频**：全数字 I2S，MAX98357A(功放)+ZTS6672×2(数字麦)，无模拟走线
- **显示**：2-lane MIPI-DSI 480×800 ST7102，12.2V/40mA 背光，触摸 3.3V 直连
- **NFC**：NT3H2111 NFC Tag Plus，手机触碰检测 + 打开 APP，数据走 C6 WiFi
- **按键**：凯华热插拔轴座 ×4 (Cherry MX 兼容)，SK6812 3215 ×4 级联 RGB 反贴背光
- **供电**：USB-C 5V 直供全板，单线供电+数据+烧录+调试
- **外设口**：USB-A 母座 (FS OTG, GPIO26/27)，独立于调试口，接机械臂/电子设备/手机，VBUS 5V 限流 500mA
