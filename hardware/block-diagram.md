# 硬件框图 (Block Diagram)

```
                         ┌───────────────────────────────────────────────┐
        USB-C (PD) ─────►│  电源: PD sink → DCDC/LDO 多路 (见 power-tree)   │
        供电+数据        │  VBUS 5V → 3V3_SYS / 1V1_P4_CORE / DVDD_DSI /   │
                         │           AVDD_AUDIO / 1V8_IO                   │
                         └───────┬───────────────────────────────────────┘
                                 │ 各路供电
   ┌─────────────────────────────┴───────────────────────────────────────┐
   │                          ESP32-P4 (主控)                             │
   │  RISC-V x2 @400MHz · PSRAM · H.264 VPU · PPA · MIPI-DSI · USB-OTG    │
   └── SDIO/SPI ──┬───── I2C ──┬───── I2S ──┬──── MIPI-DSI ──┬── GPIO ────┘
                  │            │            │                │
         ┌────────▼───┐  ┌─────▼─────┐  ┌───▼──────────┐  ┌──▼───────────┐  ┌──────────┐
         │ ESP32-C6   │  │ ES7210    │  │ ES8311 DAC   │  │ MIPI-DSI 屏  │  │ 输入/传感 │
         │ WiFi6/BLE  │  │ 4ch 麦ADC │  │ →NS4150 PA   │  │ 1024×600     │  │ 4×按键    │
         │ esp-hosted │  │ ▲ 麦阵×2-4 │  │ →喇叭        │  │ +背光升压    │  │ 竖/横在位 │
         └────────────┘  └───────────┘  └──────────────┘  │ +触摸(可选)  │  │ 传感器×2  │
                                                          └──────────────┘  │ TF卡/LED  │
                                                                            └──────────┘
        天线(C6): WiFi6 + BLE          I2C 共享总线: ES7210 / ES8311 / IO扩展(可选) / 触摸
```

## 说明
- **C6 ↔ P4**：SDIO（推荐，带宽高）或 SPI，跑 esp-hosted 固件，为 P4 提供 WiFi6/BLE。
- **音频**：I2C 配置 + I2S 数据。ES7210 TDM 4ch（含 CH1 AEC 回采参考）；ES8311 → 功放 → 喇叭，PA_EN 省电控制。
- **显示**：2-lane MIPI-DSI（视频模式）；背光需升压恒流。
- **传感/输入**：4 按键（yes/no/yes-always/panel）；竖/横槽在位传感器（ToF/微动开关）；可选霍尔、NFC、TF 卡、状态 LED。
- **供电与烧录**：USB-C 兼供电（PD）与数据（USB-OTG，作 PC 备用传输 + 烧录调试）。
