# 电源树 (Power Tree) — v1.3

> 主控: ESP32-P4C6-Core 模组 (内置 PSRAM/Flash/C6/多路 LDO)
> 更新: 2026-08-04 (v1.3: 新增 IP5306 电池+充电 / 摄像头 LDO)

## 供电拓扑

```
USB-C 5V (VBUS_IN) ── [TVS + 0Ω 跳线] 保护
  │
  └─ IP5306 (充电 + 电源路径 + 5V Boost)
        │  SW ←→ L3 (1µH) ←→ BAT+ → BAT1 (1S LiPo 3.7V/4.2V, 外接保护板)
        │  BAT- → GND
        └─ VOUT → VBUS (5V 系统轨) ──────────────────────────────── 全板 5V
              ├─ DC-DC Buck (MP2315) → +3V3 @ 2A ────────────────── 主供电轨
              │   ├─ P4C6-Core (ESP_3V3 ×2)          ~3.3V/1A
              │   ├─ 显示屏 VCC (FPC 22-23)           ~3.3V/30mA
              │   ├─ ZTS6672 ×2 (麦克风)              ~3.3V/1mA
              │   ├─ NT3H2111 (NFC Tag)               ~3.3V/5mA
              │   ├─ 触摸 IO                           ~3.3V/5mA
              │   ├─ LDO1 ME6211A28 → +2V8 ────────── 摄像头 (2026-08-04 新增)
              │   │     ├─ DOVDD (FPC pin11) 直供
              │   │     ├─ FB1 磁珠 → AVDD (pin4)
              │   │     └─ FB2 磁珠 → AF-VCC (pin23)
              │   ├─ LDO2 AMS1117-1.5 → +1V5 ──────── 摄像头 DVDD (pin10)
              ├─ VBUS 直供 (5V) ─────────────────────────────────── 音频/背光/外设/舵机
              │   ├─ MAX98357A                         ~5V/500mA (峰值)
              │   ├─ SK6812 ×4 (按键背光 LED, 级联)    ~5V/60mA
              │   ├─ USB 外设口 (PPTC 500mA 限流)      ~5V/500mA (上限)
              │   └─ 舵机云台座 ×2 (470µF 储能)         ~5V/典型 100mA, 峰值 1A
              └─ Boost (MT3608, VIN=+3V3) → LED_A ─────────────── 屏背光
                  └─ 8 LED 4串2并 (4S2P)               12.2V/40mA

机械臂 SO101 控制板 ──→ USB-A 口 (数据) + 独立电源 (不走主板 5V 轨)
```

- **USB 插入**: IP5306 直通 5V→VOUT, 同时给电池充电。
- **USB 拔掉**: IP5306 电池升压 5V→VOUT, 无缝切换 (电池 3.0~4.4V, 选 4.2V 截止)。
- 全板 5V 拓扑零改动, 只是 VBUS 来源从 USB-C 换成 IP5306 VOUT。

| 按键背光 LED | 0.15W | 0.3W | SK6812 ×4 |
| USB 外设口 | 0.1W | 2.5W | 外设, PPTC 上限 2.5W |
| 舵机云台 | 0.5W | 5W | 2× 舵机, 470µF 储能 |
| 其他 (NFC/麦) | 0.1W | 0.1W | |
| **合计** | **~5.35W** | **~15W** | |

> USB-C 5V/3A = **15W**, 常态余量 ~2.8x。峰值 (USB 外设 + 舵机同时堵转) 接近上限, 舵机动作时应避免 USB 外设口满载。
> **电池续航**: 2000-3000mAh @ 3.7V = 7.4-11Wh, 常态 5.35W → 约 **1.4~2 小时**。桌面常插电为主, 电池作移动兜底。
> IP5306 充电 ~1A (最大 2.1A), 2000-3000mAh 约 2-3 小时充满。
> 机械臂 (SO101 ×6 舵机) 走 **外部 5V 独立供电**, 不占主板电源预算。

## 设计要点

- **P4C6-Core 是模组**: 内部 PSRAM/Flash/C6 电源由模组板载 LDO 处理, 只喂 3.3V (ESP_3V3 ×2, Pin 85/86)
- **IP5306 (ESOP-8)**: VIN=VBUS_IN, VOUT=VBUS(5V), SW↔L3(1µH)↔BAT+, PowerPAD=GND。充电 2.1A 同步开关 (默认 1A 稳妥), 升压 2.4A/92%。空载自动睡眠 <100µA (P4+屏常态 >100mA, 不会误关)
- **MP2315**: 4.5-24V 宽输入, FB=0.8V, R_FBH=40.2kΩ/R_FBL=12.7kΩ → Vout=3.33V。2A 输出, 常态 ~1.5A 余量 0.5A。**EN 接 +5V (IP5306 VOUT)** — 不能接 VBUS_IN, 否则电池模式 Buck 关闭整板断电
- **摄像头 LDO (2026-08-04 v2)**: 模块 OV5640 MIPI **24pin** 无板载稳压, 需 LDO1 **ME6211A28** (2.8V, 低压差必须 — AMS1117 的 1.0V dropout 扛不动 3.3→2.8V) + LDO2 **AMS1117-1.5** (1.5V, 裕量 1.8V 足够)。AVDD/AF-VCC 用磁珠隔离防模拟噪声; AGND/AF-GND 就近接 GND 平面。DVDD=1.5V 为 OV5640 允许上限
- **MT3608 从 3.3V 取电**: 输入 2~24V, 取稳压后 3V3 更稳。升压比 ~3.9x
- **MAX98357A / SK6812 从 VBUS 取电**: 5V 输出功率更大; SK6812 VDD_min=3.5V 需 5V
- **舵机云台**: VBUS 直供 + 470µF 储能, 峰值电流由电容兜底
- **机械臂**: USB-A 口仅传数据 (控制板独立供电, 舵机电流不经过主板), USB-A VBUS 500mA 仅作枚举检测
- **去耦**: 每 IC VDD 就近 100nF, 电源入口 10µF; SK6812 每灯 100nF + 总线 100µF; 电池侧 C_BAT (100µF+22µF+100nF)
- **测点**: +3V3、VBUS、BAT+、LED_A 各留测试点
- **无模拟分区**: 全数字链路, 单 GND 平面 (摄像头 AVDD/AF-VCC 用磁珠, AGND/AF-GND 就近接平面, 无需切地)
