# 电源树 (Power Tree) — v1.1

> 主控: ESP32-P4C6-Core 模组 (内置 PSRAM/Flash/C6/多路 LDO)
> 更新: 2026-07-31

## 供电拓扑

```
USB-C 5V (VBUS)
  │
  ├─ [TVS + 0Ω 跳线] 保护
  │
  ├─ (可选) CH224K PD → 协商 9V, 5V 回退
  │
  ├─ DC-DC Buck (MP2315) → +3V3 @ 2A ──────────────── 主供电轨
  │   ├─ P4C6-Core (ESP_3V3 ×2)          ~3.3V/1A
  │   ├─ 显示屏 VCC (FPC 22-23)           ~3.3V/30mA
  │   ├─ ZTS6672 ×2 (麦克风)              ~3.3V/1mA
  │   ├─ NT3H2111 (NFC Tag)               ~3.3V/5mA
  │   └─ 触摸 IO                           ~3.3V/5mA
  │
  ├─ VBUS 直供 (5V) ───────────────────────────────── 音频功放 + 按键背光
  │   ├─ MAX98357A                         ~5V/500mA (峰值)
  │   └─ SK6812 ×4 (按键背光 LED, 级联)    ~5V/60mA (全白 50mA+)
  │
  └─ Boost (MT3608, VIN=3.3V) → LED_A ─────────────── 屏背光
      └─ 8 LED 4串2并                      12.2V/40mA
```

## 各路预算

| 电源轨 | 电压 | 电流 | 功率 | 来源 | 说明 |
|--------|------|------|------|------|------|
| VBUS | 5V (9V) | — | — | USB-C | PD 协商后 9V，回退 5V |
| +3V3 | 3.3V | ~1.2A | 4.0W | MP2315 Buck | 主供电，P4C6 ~1A + 外设 + 触摸 ~0.2A |
| LED_A | 12.2V | 40mA | 0.5W | MT3608 Boost | 屏背光 (数据手册第 8 页) |
| PA_VDD | 5V | 500mA | 2.5W | VBUS 直供 | MAX98357A 峰值, 平均远低于此 |
| LED_VDD | 5V | 60mA | 0.3W | VBUS 直供 | SK6812 ×4 全白峰值 |

## 总功耗

| 负载 | 典型 | 峰值 | 备注 |
|------|------|------|------|
| P4C6-Core | 3.3W | 3.3W | 1A@3.3V, WiFi+硬解满负载 |
| 显示屏逻辑 | 0.1W | 0.1W | VCC 3.3V/30mA |
| 背光 | 0.5W | 0.5W | 12.2V/40mA |
| 音频功放 | 0.1W | 2.5W | TTS 平均 <0.1W, 峰值 2.5W |
| 按键背光 LED | 0.15W | 0.3W | SK6812 ×4 |
| 其他 (NFC/麦) | 0.1W | 0.1W | |
| **合计** | **~4.25W** | **~6.8W** | |

> USB-C 5V/3A = **15W**，余量 2.2x（典型）。开发板实测 P4+SPI 屏仅 ~2W，最终板功耗估算偏保守。
> 如需 PD 9V，总功率不变但电流减半，Buck 效率更高。

## 与开发板的差异

| | WT9932P4-TINY | 最终板 |
|---|---|---|
| 供电接口 | Micro USB / USB-C | USB-C |
| 稳压 | 板载 LDO (3.3V) | MP2315 Buck (3.3V) + MT3608 Boost (背光) |
| PD | 无 | CH224K (可选) |
| 音频供电 | 无 | VBUS 直供 MAX98357A |
| LED 供电 | 无 | VBUS 直供 SK6812 ×4 |
| 1.8V | 无需求 | — | 触摸 3.3V 直连, 无需电平转换 |
| 模拟电源 | 无 | 无 (全数字链路) |

## 设计要点

- **P4C6-Core 是模组**：内部 PSRAM/Flash/C6 的电源已由模组板载 LDO 处理，只需喂 3.3V (ESP_3V3 ×2, Pin 85/86)
- **MP2315 选型**：4.5-24V 宽输入，5V/9V 都能工作。FB=0.6V, R_FBH=100kΩ/R_FBL=22kΩ → Vout=3.33V
- **MT3608 从 3.3V 取电**：最高输入 6V，不能接 VBUS。升压比 3.7x (3.3→12.2V)
- **MAX98357A 从 VBUS 取电**：5V 供电输出功率更大，比 3.3V 好
- **SK6812 ×4 从 VBUS 取电**：3215 反贴灯 VDD_min=3.5V，5V 直供颜色准确，GPIO51(3.3V) 直驱数据线实测可行
- **去耦**：每个 IC 的 VDD 就近放 100nF，电源入口放 10µF；SK6812 每灯一个 100nF + 总线 100µF
- **测点**：+3V3、VBUS、LED_A 各留一个测试点
- **无模拟分区**：全数字链路，单 GND 平面，不用磁珠切 AGND
