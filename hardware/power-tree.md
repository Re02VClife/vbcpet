# 电源树 (Power Tree) — v0 草案

> 电压/电流为**规划预算**，需按最终器件数据手册核算。桌面常插电，MVP 以 **USB-C 供电**为主，暂不做电池。

```
USB-C VBUS (5V, PD)
   │  [TVS + eFuse/保险丝 过流过压保护]
   │
   ├─► (可选) PD sink 协商 5V/9V ── 简单场景固定 5V
   │
   ├─► DCDC1 (Buck) ──► 3V3_SYS  ── 系统主 3.3V（数字域、C6、逻辑、传感器、TF、LED）
   │                        │
   │                        ├─► LDO_A ──► AVDD_AUDIO 3.3V（ES7210/ES8311 模拟，单独滤波）
   │                        └─► LDO_IO ─► 1V8_IO（P4/屏 IO 电平，若需要）
   │
   ├─► DCDC2 (Buck) ──► 1V1_P4_CORE ── P4 内核（大电流，靠近 P4，低纹波）
   │
   ├─► DCDC3 (Buck) ──► DVDD_DSI / PLL（MIPI-DSI 相关电源，据 P4 手册分档）
   │
   └─► 背光升压 (Boost/恒流) ──► LED_BL（屏背光，PWM 调光）
```

## 各路预算（占位，待核算）

| 电源轨 | 电压 | 估算电流 | 负载 | 器件建议 |
|---|---|---|---|---|
| 3V3_SYS | 3.3V | ~500mA+ | C6、逻辑、传感器、TF、LED | 同步 Buck，效率优先 |
| 1V1_P4_CORE | ~1.1V ⚠️ | 峰值较大 | P4 内核 | 低纹波 Buck，紧靠 P4 |
| DVDD_DSI/PLL | 按手册 ⚠️ | — | DSI/PLL | 据 P4 电源分档 |
| AVDD_AUDIO | 3.3V | ~50mA | ES7210/ES8311 模拟 | LDO，独立 π 滤波 |
| 1V8_IO | 1.8V | 视需要 | IO 电平 | 若外设需 1.8V |
| LED_BL | 屏定 | 屏定 | 背光 | 升压恒流 + PWM |

> ⚠️ **P4 电源分档以官方硬件设计指南/数据手册为准**（core、IO、PSRAM、DSI、USB 各有要求）；用模组时多数已内建，只需喂主输入。

## 设计要点
- **上电时序**：按 P4 手册要求各轨上电顺序（core / IO / 外设），必要时加时序控制。
- **去耦**：每路就近去耦；P4 core 大电流路径短、铜厚足。
- **模拟隔离**：音频 AVDD 单独 LDO + 磁珠/π 滤波；模拟地与数字地单点相连。
- **测点**：每条主轨预留测试点，方便 bring-up 分区排查。
- **功耗预算**：Phase 0 实测 P4 硬解+DSI+C6 联网+音频满负载电流，据此定 DCDC 额定与 PD 档位。
