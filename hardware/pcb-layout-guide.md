## 一、MIPI-DSI 差分对（最优先级）

### 电气参数

| 参数 | 要求 | 原因 |
|------|------|------|
| 差分阻抗 | **100Ω ±10%** | D-PHY 规范 |
| 对内等长 | **≤0.25mm**（P/N 相差） | 差分信号偏斜导致眼图闭合 |
| D0/D1 对间等长 | **≤5mm**（放宽至 10mm 也行） | lane-to-lane skew，ST7102 有 deskew 缓冲 |
| Clock vs Data 等长 | **Clock 比 Data 长 0~2mm** 或等长 | 时钟先到→数据建立时间余量 |
| 层 | **同层走完，不换层** | 过孔带来阻抗突变 |
| 包地 | **两侧走 GND 铜皮 + 打过孔接地** | 隔离串扰 |
| 差分对间距 | **≥3倍线宽**（对与对之间） | 串扰控制 |

### 推荐走法（Top 层）

> ⚠️ 2026-08-05 已按当前网表修正: 差分对在 FPC 座侧为 D0→13/14, D1→16/17, CP/CN→19/20 (三对各自相邻)。

```
D0P ────────────────────  FPC14
D0N ────────────────────  FPC13
  (间距=线宽, 两侧GND铜皮包地)
D1P ────────────────────  FPC17
D1N ────────────────────  FPC16
CLKP ───────────────────  FPC20
CLKN ───────────────────  FPC19
```

> ⚠️ **交叉不可避免**: 模组侧差分顺序 (pin34→39) 是 `D1, CLK, D0`, FPC 座侧 (pin13→20) 是 `D0, D1, CLK` — 循环错位, 无论怎么摆件/旋转, **至少一对要绕线**, 不是接错。
>
> 交叉分两类 (都要在布局层解决, 不需要改模组 — 模组引脚是物理固定的):
> - **对内 P/N 镜像**: D0、D1 两对 (模组侧 P,N ↔ 屏座侧 N,P); CLK 同为 N,P 不镜像。处理: DSI **lane 极性翻转** (标准 MIPI 特性, 驱动+屏 IC 都支持) 或同层绕一个毫米级小弯, 代价 <0.5mm, 远小于对内 ≤0.5mm 预算。
> - **对间错位**: D1↔CLK 结构性错位, 永远躲不掉 — **CLK 是锚点**。处理: 其中一对 C 形绕线。
>
> 处理方式 (推荐):
> 1. 摆件时让 **D0 对直通** (模组 pin38/39 正对 FPC pin13/14), 只剩 D1↔CLK 一对错位。
> 2. 让 **D1 对走 C 形绕线**绕过 CLK (同层 Top, 不过孔不换层), 多走几 mm — 远小于 ≤5mm 对间 skew 预算, 500Mbps 无感。
> 3. **CLK 保持最短最直** (时序基准, 不做绕线的那对)。
> 4. 不要用单个过孔跳层来"交叉" — 阻抗突变; 若实在要换层, 差分对**成对一起换**并双侧过孔缝合。
>
> **扇出 (fanout)**: 模组 25×25mm、88 脚周边邮票孔, 焊盘中心距 ~0.8mm (31mil), 相邻间隙 ~10mil。所有脚都在边缘 → **走线垂直向外扇出, 不需要从焊盘间挤过去**。每个脚先引 **4mil 细线**出去 3~5mm, 到开阔区再汇成 4.5mil/8mil 的 100Ω 对 (中心距 31mil→12.5mil 收敛)。扇出段几 mm 非受控阻抗在 500Mbps 可接受。差分对**不要**在焊盘间直接成型。

### 嘉立创 4 层板参考叠层

用 JLC04161H-7628 叠层，差分 100Ω 线宽/间距在官网阻抗计算器 (tools.jlc.com, 选 JLC04161H-7628) 反算，实测参考值：

```
线宽 ≈ 7.3mil / 间距 ≈ 6mil   (2026-08-07 JLC04161H-7628 通用款官网计算器实测, 唯一正确值)
```

> ⚠️ 板子叠层 = **JLC04161H-7628 通用免费款** (L1-L2 单层 7628 ≈ 8.28mil)。下单/计算器必须选这款 (带"通用"或无后缀); 7628A/7628B/3313A 是特殊款叠层, 阻抗数值全不适用。100Ω 差分外层 = 7.3/6mil。

## 一·五、MIPI-CSI 差分对（摄像头, 2026-08-05 新增）

### 电气参数

| 参数 | 要求 | 原因 |
|------|------|------|
| 差分阻抗 | **100Ω ±10%** | D-PHY 规范, 与 DSI 同 |
| 对内等长 | **≤0.5mm** (理想 ≤0.25mm) | 2-lane 1080p@30 ≈ 500Mbps/lane, 略松于 DSI 但仍求紧 |
| 对间等长 | ≤5mm | lane-to-lane skew |
| Clock vs Data | Clock 比 Data 长 0~2mm 或等长 | 时钟先到 |
| 层 | **同层走完, 不换层** | 过孔阻抗突变 |
| 包地 | 两侧 GND 铜皮 + 过孔 | 隔离串扰 |
| 对间距 | ≥3 倍线宽 | 串扰 |

### 走线 (Top 层, 与 DSI 分区域)

```
CSI_D1P ── CN1:12  CSI_D0P ── CN1:20
CSI_D1N ── CN1:13  CSI_D0N ── CN1:22
CSI_CLKP ─ CN1:16  CSI_CLKN ─ CN1:18
```

- **远离背光 Boost (MT3608 12.8V 开关) 与 5V/舵机大电流线** — CSI 最敏感。
- 摄像头座放板边, FPC 走线最短; MIPI 从 M1 到 CN1 尽量直。
- CAM_MCLK (24MHz 时钟) 单端走线, 远离高频源, 与 CSI 差分包地共用 GND。

## 二、RF 天线（C6 2.4GHz）

| 参数 | 要求 |
|------|------|
| 特性阻抗 | **50Ω 单端** |
| 走线长度 | **尽量短**（<15mm 理想） |
| 拐角 | **圆弧或 45° 切角**，禁止 90° 直角 |
| 参考层 | 下方完整 GND 平面（第二层） |
| 周围 | λ/4 内不要铺地（≈17mm），两侧 GND 间距 ≥ 3 倍线宽 |
| 过孔 | **0 个过孔** |

> 2026-08-05: 板上 U4 (IPEX) 已删, **模组自带 IPEX 天线座**, LAN_OUT (M1:2) 留空。
> 天线 (u.FL 软天线) 直接扣模组自带座, 无需板载 50Ω 走线 — 但天线本体仍要远离噪声源 (MP2315/IP5306/MT3608 SW 区)。

## 三、USB 2.0 DP/DM

| 参数 | 要求 |
|------|------|
| 差分阻抗 | **90Ω ±15%** |
| 对内等长 | **≤1mm**（FS 12Mbps 不严格） |
| 长度 | <50mm 随便走 |

> P4 只跑 Full-Speed (12Mbps)，要求远低于 HS (480Mbps)。等长随便做，阻抗差不多就行。

## 四、I2S 音频

| 参数 | 要求 |
|------|------|
| BCLK/WS/DOUT 等长 | **≤20mm**（3MHz，基本不用在意） |
| DIN（麦输入）| 同上，短粗即可 |
| 远离 | **MP2315 SW 节点、MT3608 SW 节点**（开关噪声） |

> 3MHz 的 I2S 不是高速信号，不要靠近 DC-DC 的电感 / SW 脚就行。

## 五、电源布局（IP5306 + MP2315 + MT3608 + 摄像头 LDO）

### 5.0 IP5306 电池路径（2026-08-05 新增）

```
VBUS_IN ── C(10µF) ─ GND        ← VIN 输入去耦紧贴芯片
              │
       IP5306 VIN
        SW ── L3(1µH) ──┬─ BAT+ ── 电池
        VOUT ── C(22µF) ─ GND     │
             └─ +5V 系统轨        └─ C_BAT(100µF+22µF+100nF) 紧贴 BAT
```

| 规则 | 说明 |
|------|------|
| **L3 靠近 IP5306** | SW↔L3↔BAT 环路最小, 开关节点短粗 |
| **BAT+ 粗线** | ≥1mm (充电 1A + 放电升压电流) |
| **C_BAT 紧贴 BAT+ 引脚** | 100µF+22µF+100nF, 电池路径去耦 |
| **VBUS_IN/VOUT 去耦** | 输入 10µF、输出 22µF 各紧贴对应引脚 |
| 电池座 | 远离天线/摄像头/雷达; 电池路径 GND 直接回主平面 |

### 5.1 MP2315 Buck

```
VIN(+5V) ─┬─ C(10µF) ─ GND     ← 输入电容紧贴 IN-GND
          └─ IN
SW ─ L1 ──┬─ C(22µF) ─ GND     ← 输出
          └─ +3V3
BST ─ C_BST(100nF) ─ R(20Ω) ─ SW
VCC ─ C(0.1µF) ─ GND
FB ──[远离SW]── R_FBH(40.2k) → +3V3
             └ R_FBL(12.7k) → GND
EN ─ +5V (IP5306 VOUT)
```

| 规则 | 说明 |
|------|------|
| **输入电容紧贴 IN-GND** | 输入环路最小化 |
| **SW 走线最短最粗** | 几百 kHz 方波, 铜皮面积 = 天线 |
| **FB 远离 SW/L1** | 反馈是模拟信号, 别靠近开关节点的噪声区 |
| **EN 接 +5V** | 电池模式也要保持使能 |
| **L1 方向** | SW→L1→输出电容路径直线, 电流单向流 |

### 5.2 MT3608 Boost

```
+3V3 ── L2(10µH) ── SW
                     SW ── D1(SS14) ──┬─ LED_A
                                      └─ C(1µF) ─ GND
                     FB ── R(15Ω) ── GND
```

| 规则 | 说明 |
|------|------|
| L2→SW→D1 环路最小 | SW 方波节点最短 |
| D1→C→GND 回流紧 | 输出电容地直接回 GND |
| R(15Ω) 靠近 FB | 恒流检测电阻, 线不要太长 |

### 5.3 摄像头 LDO（2026-08-05 新增）

```
+3V3 ── LDO1 XC6206/ME6211 (2.8V) ──┬─ +2V8 ── DOVDD 直供
                                    ├─ FB1磁珠 ─ AVDD
                                    └─ FB2磁珠 ─ AF-VCC
+3V3 ── LDO2 AMS1117-1.5 (1.5V) ── +1.5V ── DVDD (TAB→VOUT)
```

| 规则 | 说明 |
|------|------|
| **LDO 靠近摄像头座** | 输出走线最短 |
| **+2V8/+1.5V 输出电容** | 各 1µF+100nF 紧贴 LDO 输出引脚 |
| **FB1/FB2 磁珠** | AVDD/AF-VCC 模拟轨隔离, 靠近摄像头座 |
| **AMS1117 TAB 焊盘** | 接 +1.5V 铜皮散热 (SOT-223) |
| AMS1117 地 | 直接回 GND 平面 |

## 六、NFC PCB 天线

```
NT3H2111 LA ──── PCB 线圈 3~4 匝 ──── NT3H2111 LB
   （匹配元件 2026-08-05 起不接, 直接线圈; 谐振不足时再补 22pF 并联）
```

| 规则 | 说明 |
|------|------|
| 匝数 | 3~4 匝，25×25mm 方形，线宽 0.5~1mm，线距 0.5mm |
| 对称 | 两端走线严格对称，长度一致 |
| GND 禁空 | 线圈正下方及周围 5mm **不要铺地**（涡流损耗） |
| 远离铜皮 | 离电池、USB 座、大电容远一点 |
| 匹配(可选) | 读距不足时: LA/LB 各串 2.2Ω + 对地并联 22pF 调试 (NT3H2111 参考设计) |

## 七、去耦 + GND 通用规则

| 规则 | 说明 |
|------|------|
| **4 层板** | Top(Sig) / L2(GND 完整) / L3(Pwr+Sig) / Bot(Sig) |
| 每个 IC 的 100nF | **紧贴 VDD 引脚**，另一端直接打过孔到 L2 GND |
| 电解/钽电容 | 放 IC 附近，不用紧贴 |
| GND 过孔 | 关键 IC 至少 2~3 个 GND 过孔（减小电感） |
| 晶振/时钟 | 下方不铺铜（P4C6 模组自带，不用管） |
| 板边 | GND 铜皮缩进 0.5mm（防板边毛刺短路） |

## 九、嘉立创 EDA 操作要点

1. **先设叠层**：`设计 → 层管理器 → 4 层`，JLC04161H-7628
2. **差分对**：原理图中选中 DP/DM 或 DSI P/N → 右键 `差分对`
3. **阻抗计算**：`工具 → 阻抗计算器`，输入叠层参数，得到线宽/间距
4. **等长调线**：走完后用 `差分对等长调节` 工具做蛇形线补偿
5. **DRC**：提交前跑一遍，重点关注 `差分对内长度差` 检查项

## 十、不做的事

- ❌ 不做 AGND/DGND 分割（单 GND 平面; 摄像头 AGND/AF-GND 就近接平面即可）
- ❌ 不做磁珠隔离 — ⚠️ 例外: **摄像头 AVDD/AF-VCC 用 FB1/FB2 磁珠**隔离模拟噪声 (其余不加)
- ❌ 不做 MIPI 等长到 ps 级（DSI ~330Mbps/lane 有 deskew; CSI 1080p@30 ~500Mbps/lane, 对内 ≤0.5mm 足够）
- ❌ 不做阻抗控制以外的特殊 stackup（JLC 标准 4 层即可）
