# PCB 布局布线指南 — vbcpet 桌宠主板

> 版本: v1.0 | 日期: 2026-07-31 | 层数: 4 层

## 信号优先级总览

| 优先级 | 信号 | 可控阻抗 | 等长要求 | 备注 |
|--------|------|---------|---------|------|
| 🔴 **最高** | MIPI-DSI | 100Ω 差分 | ≤0.25mm 对内 | 差分对，最敏感 |
| 🔴 **最高** | C6 RF | 50Ω 单端 | — | 2.4GHz，短直 |
| 🟡 **中** | USB DP/DM | 90Ω 差分 | ≤1mm | FS 不严格 |
| 🟡 **中** | Buck/Boost SW 节点 | — | — | 短粗，最小化 |
| 🟢 **低** | I2S | — | ≤20mm | 音频，宽松 |
| 🟢 **低** | I2C | — | — | 100kHz/400kHz |
| 🟢 **低** | SK6812 数据线 | — | — | 800kHz 单线 |
| 🟢 **低** | 按键 / GPIO | — | — | 随便走 |

## 一、MIPI-DSI 差分对（最优先级）

### 电气参数

| 参数 | 要求 | 原因 |
|------|------|------|
| 差分阻抗 | **100Ω ±10%** | D-PHY 规范 |
| 对内等长 | **≤0.25mm**（P/N 相差） | 差分信号偏斜导致眼图闭合 |
| D0/D1 对间等长 | **≤5mm**（放宽至 10mm 也行） | lane-to-lane skew，ST7102 有 deskew 缓冲 |
| Clock vs Data 等长 | **Clock 比 Data 长 0~2mm** 或等长 | 时钟先到→数据建立时间余量 |
| 层 | **同层走完，不换层** | 过孔带来阻抗突变 |
| 包地 | **两侧走 GND 铜皮 + 打过孔接地** | 隔离串扰 |
| 差分对间距 | **≥3倍线宽**（对与对之间） | 串扰控制 |

### 推荐走法（Top 层）

```
D1P ────────────────────  FPC14
D1N ────────────────────  FPC15
  (间距=线宽, 两侧GND铜皮包地)
CLKN ───────────────────  FPC12
CLKP ───────────────────  FPC11
D0P ────────────────────  FPC17
D0N ────────────────────  FPC18
```

### 嘉立创 4 层板参考叠层

用 JLC04161H-7628 叠层，差分 100Ω 线宽/间距以 EDA 阻抗计算器为准，参考值：

```
线宽 ≈ 4.5mil / 间距 ≈ 8mil
```

## 二、RF 天线（C6 2.4GHz）

| 参数 | 要求 |
|------|------|
| 特性阻抗 | **50Ω 单端** |
| 走线长度 | **尽量短**（<15mm 理想） |
| 拐角 | **圆弧或 45° 切角**，禁止 90° 直角 |
| 参考层 | 下方完整 GND 平面（第二层） |
| 周围 | λ/4 内不要铺地（≈17mm），两侧 GND 间距 ≥ 3 倍线宽 |
| 过孔 | **0 个过孔**，从 Pin2 到 IPEX 焊盘直走 |

```
P4C6_Pin2(LAN_OUT) ─────[直走]───── IPEX1 焊盘
                           ↑
                     50Ω, 短, 无过孔
```

## 三、USB 2.0 DP/DM

| 参数 | 要求 |
|------|------|
| 差分阻抗 | **90Ω ±15%** |
| 对内等长 | **≤1mm**（FS 12Mbps 不严格） |
| 长度 | <50mm 随便走 |

> P4 只跑 Full-Speed (12Mbps)，要求远低于 HS (480Mbps)。等长随便做，阻抗差不多就行。

---

## 四、I2S 音频

| 参数 | 要求 |
|------|------|
| BCLK/WS/DOUT 等长 | **≤20mm**（3MHz，基本不用在意） |
| DIN（麦输入）| 同上，短粗即可 |
| 远离 | **MP2315 SW 节点、MT3608 SW 节点**（开关噪声） |

> 3MHz 的 I2S 不是高速信号，不要靠近 DC-DC 的电感 / SW 脚就行。

## 五、电源布局（MP2315 Buck + MT3608 Boost）

### 5.1 MP2315 Buck

```
VIN ─┬─ C4(10µF) ─ GND
     └─ U7_Pin2(VIN)

U7_Pin3(SW) ─ L1 ──┬─ C5(22µF) ─ GND
            └─ C_BST(100nF) ─ Pin6(BST)
                   └─ +3V3 输出

U7_Pin5(FB) ──[远离SW]──→ R_FBH(100k) → +3V3
                       └→ R_FBL(22k) → GND
```

| 规则 | 说明 |
|------|------|
| **C4 紧贴 VIN-GND** | 5mm 以内，输入环路最小化 |
| **SW 走线最短最粗** | SW 是几百 kHz 的方波，铜皮面积 = 天线 |
| **FB 远离 SW/L1** | 反馈是模拟信号，别靠近开关节点的噪声区 |
| **GND 铺铜** | Buck 的 GND 直接打过孔到底层 GND 平面 |
| **L1 方向** | 让 SW→L1→C5 的路径呈直线，电流单向流 |

### 5.2 MT3608 Boost

```
+3V3 ── L2(10µH) ── U9_Pin1(SW)
                     U9_Pin1 ── D2(SS14) ──┬─ LED_A
                                          └─ C9(1µF) ─ GND
                     U9_Pin3(FB) ── R5(15Ω) ── GND
```

| 规则 | 说明 |
|------|------|
| L2→SW→D2 环路最小 | 跟 Buck 一样，SW 方波节点最短 |
| D2→C9→GND 回流紧 | 输出电容地要直接回到 GND |
| R5 靠近 FB | 恒流检测电阻，线不要太长 |

## 六、NFC PCB 天线

```
NT3H2111 LA ── R12(2.2Ω) ── C13(调试) ──┐
                                         ├── PCB 线圈 3~4 匝 ──┐
NT3H2111 LB ── R13(2.2Ω) ── C14(调试) ──┘                    │
         C15(22pF)─┬─ C16(22pF)                               │
                   GND                                          │
         ┌─────────────────────────────────────────────────────┘
         └── 线圈末端回到 LB
```

| 规则 | 说明 |
|------|------|
| 匝数 | 3~4 匝，25×25mm 方形，线宽 0.5~1mm，线距 0.5mm |
| 对称 | 两端走线严格对称，匹配电容等长 |
| GND 禁空 | 线圈正下方及周围 5mm **不要铺地**（涡流损耗） |
| 远离铜皮 | 离电池、USB 座、大电容远一点 |
| 匹配 | C13/C14 值调试定（NT3H2111 参考设计 ~22pF） |

## 七、去耦 + GND 通用规则

| 规则 | 说明 |
|------|------|
| **4 层板** | Top(Sig) / L2(GND 完整) / L3(Pwr+Sig) / Bot(Sig) |
| 每个 IC 的 100nF | **紧贴 VDD 引脚**，另一端直接打过孔到 L2 GND |
| 电解/钽电容 | 放 IC 附近，不用紧贴 |
| GND 过孔 | 关键 IC 至少 2~3 个 GND 过孔（减小电感） |
| 晶振/时钟 | 下方不铺铜（P4C6 模组自带，不用管） |
| 板边 | GND 铜皮缩进 0.5mm（防板边毛刺短路） |

## 九、嘉立创 EDA 操作要点

1. **先设叠层**：`设计 → 层管理器 → 4 层`，JLC04161H-7628
2. **差分对**：原理图中选中 DP/DM 或 DSI P/N → 右键 `差分对`
3. **阻抗计算**：`工具 → 阻抗计算器`，输入叠层参数，得到线宽/间距
4. **等长调线**：走完后用 `差分对等长调节` 工具做蛇形线补偿
5. **DRC**：提交前跑一遍，重点关注 `差分对内长度差` 检查项

---

## 十、不做的事

- ❌ 不做 AGND/DGND 分割（全数字链路，单 GND 平面即可）
- ❌ 不做磁珠隔离（没必要）
- ❌ 不做 MIPI 等长到 ps 级（4.3" 480×800 数据率仅 ~330Mbps/lane，ST7102 有 deskew）
- ❌ 不做阻抗控制以外的特殊 stackup（JLC 标准 4 层即可）
