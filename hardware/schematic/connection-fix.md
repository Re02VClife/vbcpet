## ① MP2315 Buck 3.3V — ✅ 已确认 (2026-08-02)

netlist 现状: IN/EN 已接, **SW/FB/VCC 全空**。datasheet 核实后外围如下:

| MP2315 引脚 | 接法 | 元件 | 状态 |
|---|---|---|---|
| IN | VBUS | C1/C2 10µF×2 (已有) | ✅ |
| EN | VBUS | — | ✅ |
| SW | → L1 → +3V3 | **L1 = 4.7µH** (空置, 官方 3.3~4.7µH 相符) | ⬜ 待接 |
| FB | → R6 → +3V3;→ R11 → GND | **R6 = 40.2kΩ 1% / R11 = 12.7kΩ 1%** | ⬜ **阻值需改** |
| VCC | → C → GND | **100nF (≤0.22µF)** | ⬜ 新增 |
| BST | → C + R 串联 → SW | **100nF + 20Ω** | ⬜ 新增 |
| GND/EP | GND | | ✅ |

**关键修正(3 处):**
1. **FB 基准 = 0.8V**,不是 0.6V。原 R6=100k/R11=22k 若接上会输出 **4.44V**(烧屏/烧模组)。改为 datasheet Table 1 推荐值:
   ```
   Vout = 0.8 × (1 + 40.2k/12.7k) = 0.8 × 4.165 = 3.33V ✅
   ```
2. **VCC 去耦 = 0.1µF**,绝不能超 0.22µF(空置 C5=1µF 不可用,需新增)。
3. **BST = 100nF + 20Ω 串联**接 SW~BST(串联顺序参照 datasheet 典型应用图;参考立创开源 MP_2315_ADJ)。

> AAM 脚: 可加 T 型网络(Rt≈4kΩ)优化轻载效率, 非必须, 先不接。

**元件变更:** R6 100k→**40.2k 1%**, R11 22k→**12.7k 1%**;新增 VCC 0.1µF、BST 100nF+20Ω。

## ② MT3608 背光升压 — ✅ 已确认

引脚 (SOT-23-6): **1=SW, 2=GND, 3=FB, 4=EN, 5=IN, 6=NC**

| MT3608 引脚 | 接法 | 元件 |
|---|---|---|
| IN (5) | +3V3 | 22µF + 100nF 去耦 |
| EN (4) | BL_PWM = GPIO48 | EN 高≥1.5V, 3.3V 可直驱 |
| SW (1) | → L2 10µH → D2(SS14)阳极 | L2 = 10µH |
| D2 阴极 | → LED_A | SS14 肖特基 |
| FB (3) | ← LEDK 节点(采样电阻上端) | 恒流 |
| GND (2) | GND | |

**恒流链路:**
```
LED_A → FPC 1-2 → 屏内 4S2P → FPC 4-5(LEDK) → R5(15Ω 1%) → GND
                                               └──► FB
```
- I = FB(0.6V) / R5 = 0.6V / 15Ω = **40mA**(手册确认)
- 参数: VIN 2~24V, SW 限流 4A, 输出 max 28V, 1.2MHz → 3.3V→12.8V 完全在规格内
- LED_A → C9(1µF)→ GND 可加, 压输出纹波

## ⑥ MAX98357A (CH98357) — ⚠️ 需改 1 处

| 引脚 | 连接 | 状态 |
|---|---|---|
| 7/8 VDD | VBUS (5V, 2.5~5.5V OK) | ✅ |
| 4 SD_MODE | PA_EN (GPIO46, 高=使能, 内部 100k 下拉) | ✅ |
| **2 GAIN** | GND → **12dB** | ⚠️ **原标"3dB"错误** |
| 1 DIN / 14 LRCLK / 16 BCLK | I2S0 | ✅ |
| 9/10 OUTP/OUTN | SPK+/- | ✅ |

> GAIN 增益表 (I2S 模式): GND经100k=**15dB**, GND=**12dB**, 浮空=**9dB**, VDD=**6dB**, VDD经100k=**3dB**。
> 原设计标 "GND(3dB)" 应为 **12dB**; 若需 3dB 需 GAIN 经 100kΩ→VDD。
> SD_MODE 同时选择左右声道, 需与固件 I2S 数据声道匹配。

## ⑦ ZTS6672 ×2 麦克风 — ✅ 已确认

- VDD 1.6~3.6V → +3V3; 每颗就近 0.1µF 去耦

- SELECT: MK1 → GND (左声道), MK2 → +3V3 (右声道) ✅
- DATA 共用 I2S_DIN; BCLK/WS 共用 I2S0
