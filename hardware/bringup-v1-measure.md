# V1 板 GPIO 电平实测记录

> 由 tools/gp_sweep.py 生成 | 端口 COM23 @ 115200
> 目的: 定 pin66/pin76 身份、C6 三根线可用性、背光换脚候选

| 步 | 命令 | 量点 | 读数 (V) | 说明 |
|---|---|---|---|---|
| 1 | gp 48h | pin76 | 1.33 | 驱动 GPIO48 输出高 |
|  |  | pin66 | 1.24 |  |
| 2 | gp 48l | pin76 | 0 | 驱动 GPIO48 输出低 |
|  |  | pin66 | 1.24 |  |
| 3 | gp 30h | pin57 | 2.93 | 驱动 GPIO30 输出高 |
| 4 | gp 31h | pin58 | 3.24 | 驱动 GPIO31 输出高 |
| 5 | gp 32h | pin59 | 3.24 | 驱动 GPIO32 输出高 |
| 6 | gp 34h | pin61 | 3.24 | 驱动 GPIO34 输出高 |
| 7 | gp 49h | pin77 | 3.25 | 驱动 GPIO49 输出高 |
| 8 | gp 50h | pin78 | 3.25 | 驱动 GPIO50 输出高 |
| 9 | gp 33h | pin60 | 3.24 | 驱动 GPIO33 输出高 (带负载对照) |

## 判读

- 步 1/2: pin76 跟着 48h/48l 变 -> 手册没错(pin76=GPIO48); pin66 跟着变 -> 手册 66/76 写反了
- 步 3/4/5: pin57/58/59 约 3.3V -> 三根线可接 C6 当串口编程器; 约 1.2V -> 必须换脚
- 步 6/7/8: 谁约 3.3V 谁就能当背光 PWM (替代 GPIO48)
- 步 9: 与 NC 脚对比, 看有负载时会不会被拉低
