# PCB 工程 (KiCad) 与布线约束

> 此目录存放 KiCad PCB（`.kicad_pcb`）、叠层、布线规则、Gerber/装配输出。当前为约束占位，待原理图完成后布局布线。

## 叠层（建议 ≥4 层）
`Top(信号) / GND / PWR / Bottom(信号)`，据高速信号密度可升 6 层。参考 ESP32-P4 模组硬件设计指南定叠层与阻抗。

## 关键布线约束
| 区域 | 约束 |
|---|---|
| **MIPI-DSI 差分对** | 对内等长、100Ω 差分阻抗、包地、远离 DCDC/数字噪声，参考层完整 |
| **C6 射频** | 天线 keepout 区、π 型匹配、天线下方无铜、50Ω 单端走线短直 |
| **SDIO (P4↔C6)** | 等长约束、时钟远离敏感信号；退化 SPI 时亦短直 |
| **PSRAM/DSI 高速** | 靠近主控、短、参考层完整（模组内建时免） |
| **音频模拟** | ES7210/ES8311 AVDD 独立滤波；麦克风走线短且对称、远离数字/DCDC；模拟地与数字地单点相连 |
| **电源** | P4 core 大电流路径宽短、就近去耦；各主轨留测试点 |
| **USB2.0** | D+/D- 差分 90Ω、等长、短 |

## 结构 / 机构
- 竖/横槽在位传感器摆位对准两个手机停靠点；ToF/红外需外壳留检测窗口，微动开关对准机械触点。
- 喇叭需声学腔；麦克风开孔位与防尘。
- 4 按键 + 面板键的面板开孔与手感。
- 屏与主板的 FPC 走线与固定。

## 输出
- `pcb/gerber/`：Gerber + 钻孔 + 装配图（BOM/CPL）。
- 出图前跑 **DRC**（含阻抗/间距/铜厚规则）。
